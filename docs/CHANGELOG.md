# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-07-07

### Added
- 🤖 **AI-Powered Q&A System**: General chat and Wikipedia-specific Q&A with Google Gemini AI
- 📝 **Enhanced Article Summarizer**: Multiple summary types (Quick, Detailed, Academic, Creative)
- 🎯 **Interactive Quiz Generator**: Take quizzes with scoring, not just generate them
- 📰 **Real-Time News Integration**: Latest world news with category and country filtering
- 📱 **Mobile-First Design**: Comprehensive mobile responsiveness across all features
- 🔄 **Cross-Tool Integration**: Seamless navigation between summarizer, Q&A, and quiz
- 🎨 **Advanced UI/UX**: Improved animations, loading states, and user feedback
- 🌐 **Multi-Language Support**: Quiz and summary generation in multiple languages
- 📊 **Quiz Analytics**: Detailed scoring and performance feedback
- 🔍 **Smart Article Search**: Enhanced search with suggestions and article selection

### Changed
- 🔄 **Complete Backend Rewrite**: Migrated from Hugging Face to Google Gemini AI
- 🎨 **UI/UX Overhaul**: Modern, responsive design with improved accessibility
- 📱 **Mobile Optimization**: Touch-friendly interactions and responsive layouts
- 🚀 **Performance Improvements**: Faster loading times and better error handling
- 📝 **Enhanced Documentation**: Comprehensive README and contributing guidelines

### Fixed
- 🐛 **Quiz Page Rendering**: Fixed malformed HTML structure
- 🔧 **Server Configuration**: Proper API routing and error handling
- 📱 **Mobile Compatibility**: Responsive design issues across devices
- 🔄 **Cross-Tool Navigation**: URL parameter passing and state management

### Technical
- ⚡ **Backend**: Node.js + Express.js with modular API structure
- 🧠 **AI**: Google Gemini AI for all text generation tasks
- 📰 **News**: NewsAPI integration with fallback mock data
- 🎨 **Frontend**: Vanilla JavaScript with modern CSS Grid and Flexbox
- 🚀 **Deployment**: Vercel-ready with environment variable configuration

## [1.0.0] - 2025-01-01

### Added
- 🔍 **Basic Wikipedia Search**: Simple search interface
- 📝 **Article Summarizer**: Basic AI-powered summaries
- 🎯 **Quiz Generator**: Generate multiple-choice quizzes
- 🎲 **Random Articles**: Discover random Wikipedia articles
- 🤖 **Basic Q&A**: Simple question-answering functionality

### Technical
- 🏗️ **Initial Architecture**: Basic Express.js server with static files
- 🤖 **AI Integration**: Hugging Face API for text generation
- 🎨 **UI**: Basic responsive design with CSS
